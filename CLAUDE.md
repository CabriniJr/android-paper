# Two projects in this repository

- The repository root is **PaperScreen**, an Android app (see `README.md`).
- `fallout-nx/` is an unrelated project: static-recompilation ports of Fallout 3 / New Vegas (Xbox 360) to the
  Nintendo Switch. When working there, read `fallout-nx/CLAUDE.md` first; its rules (no game data in git, provenance
  of symbols) apply to everything under that folder.
